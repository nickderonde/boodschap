# Beveiliging / Security

Heb je een kwetsbaarheid gevonden in BOODSCHAP! (bijvoorbeeld in de versleuteling of de deelcode)? Meld het
vertrouwelijk via **info@derondeengineering.nl**, niet via een openbaar issue. Beschrijf wat je vond en hoe het te
reproduceren is. We reageren zo snel mogelijk en vermelden je graag bij de oplossing als je dat wilt.

Found a security issue? Please report it privately to **info@derondeengineering.nl** instead of opening a public issue.

Achtergrond: `docs/ARCHITECTURE.md` (versleuteling, §6) en het privacybeleid op
https://nickderonde.github.io/boodschap/privacy/.
