## Beelden (minimaal)

1. Lijst met categorieën (licht).
2. Item toevoegen met suggesties (typ "kaa").
3. Afgevinkte items onderaan.
4. Delen met QR (lijst "Boodschappen").
5. Sync-status bovenin ("Bijgewerkt").
6. Eén van bovenstaande in donkere modus.

Ruwe beelden in `store/screenshots/raw/` (bestandsnamen bepalen de volgorde), daarna `npm run make:screenshots`.
