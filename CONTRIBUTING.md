# Bijdragen / Contributing

Fijn dat je wilt helpen. Kort:

1. Open eerst een issue met je idee of bug, zodat we kunnen afstemmen.
2. Werk in een eigen branch. Draai vóór je pull request: `npm run typecheck`, `npm test` en `npm run check:secrets`.
3. Teksten in de app zijn Nederlands en staan in `src/ui/strings.nl.ts`.
4. Nieuwe afhankelijkheden: alleen met een toegestane licentie (`npm run check:licenses`) en daarna `npm run gen:licenses`.
5. Geen analytics, tracking, advertenties of verbindingen met andere servers dan de relays (zie `docs/REQUIREMENTS.md`, NF-06).

Door bij te dragen ga je ermee akkoord dat je bijdrage onder de MIT-licentie valt.

Contributions are welcome. Please open an issue first; code comments and UI texts are in Dutch.
