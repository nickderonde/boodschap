BOODSCHAP!
Nederlands

A shared grocery list

Free app for iPhone and Android. No account, no ads, no tracking. The app's interface is in Dutch.

  • One list for the whole household: what one person adds or checks off, the others see too.
  • Works in the store without reception; changes sync as soon as you are back online.
  • Items are grouped by aisle automatically.
  • Share with a QR code or a code in your chat app. Your lists are end-to-end encrypted.
  • Open source: the code is on GitHub.
